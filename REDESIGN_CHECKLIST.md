# Portfolio audit: what made it read as AI-generated

Written before any change was made. Each item is ticked once it is fixed, with a note on what replaced it.

One thing only you can check: I wrote the new copy from facts already on the old page, but it is in your voice. Read it once and change anything you would not say.

## A. Copy

- [x] **A1. Slogan hero.** "Building AI systems that work *beyond the demo.*" says nothing about who you are. Any AI engineer could paste it onto their site.
  - Fixed: Hero is now your name and one plain sentence about what you build and where.
- [x] **A2. The same headline formula seven times.** Every section heading was "Plain statement.<br>*Italic twist.*" ("Good AI engineering is / *more than a good prompt.*", "Built, broken down / *and made better.*", "The tools behind / *the implementation.*", "More from the / *workbench.*", "Have a real problem / worth *solving?*"). One is a style. Seven is a template.
  - Fixed: Section headings are single words: Work, About, Repos. No italic twist anywhere.
- [x] **A3. Numbered all-caps kickers.** "01 / THE PERSON BEHIND THE SYSTEMS", "02 / SELECTED ENGINEERING WORK" … "06 / START A CONVERSATION". The single most recognisable generated-portfolio pattern.
  - Fixed: All numbered kickers removed.
- [x] **A4. Lists of three everywhere.** "grounded, measurable and maintainable", "understood, evaluated and operated", "reliable data, clear interfaces, useful evaluation", "thoughtful engineering conversations, challenging AI problems and useful products", three principle cards, three bullets per project.
  - Fixed: Rewritten sentence by sentence; lists carry however many items are true.
- [x] **A5. Principle cards with aphorisms.** "Ground before you generate." / "Evaluate what matters." / "Design for the real world." Poster slogans, not something a person says about their own work.
  - Fixed: Cards deleted. The two habits that were real are one sentence in About.
- [x] **A6. Abstract sentences with nothing in them.** "I work at the point where model capability meets software engineering." "An engineering foundation built around analytical problem-solving, systems thinking and working within real constraints."
  - Fixed: Replaced with concrete statements, or cut.
- [x] **A7. Third-person-ish project copy.** Projects were described the way a README summariser would ("The repository documents…", "The public README is a project description, not evidence of…"), never as "I built".
  - Fixed: Each project is described in first person, including which part you care about.
- [x] **A8. Boilerplate labels on every card.** "Explore the design decisions ＋", "Inspect repository ↗", "**Engineering questions:** a, b, c, d and e".
  - Fixed: One link per project: "Code on GitHub". Design notes are folded into the description.
- [x] **A9. Disclaimers that sound like a lawyer.** "Performance figures are intentionally omitted where the repository does not publish enough benchmark detail to interpret them independently." "Focused on technologies used in my work and public projects—not a catalogue of everything I have tried."
  - Fixed: Replaced by direct statements ("None of it has been clinically validated", "Nothing I only read about").
- [x] **A10. Fake metadata as decoration.** "PROFILE / 01", "INDIA", "01 — 06", "ENGINEERING INTELLIGENT SYSTEMS", "WORKFLOW / OVERVIEW", "FEATURED", "FILTER PROJECTS". Labels that label nothing.
  - Fixed: Removed. The labels that remain (Fig. 1 to 4, parts list, title block) label real things.
- [x] **A11. A false claim.** "Repository details sync daily from GitHub" with a pulsing live dot. They don't: the index is a file regenerated by hand. (`repositories.js` also still cited a workflow that was deleted.)
  - Fixed: Claim and live dot removed. The page now says when the list was last pulled.
- [x] **A12. Toolkit descriptions.** Four cards each with a sentence of filler ("API design, async workflows, streaming responses, application state and service integration") above the actual tool names.
  - Fixed: Now a four-row parts list: area and tools, no filler.
- [x] **A13. Generic contact pitch.** "Have a real problem worth solving?"
  - Fixed: Contact is one sentence and your email address set very large.
- [x] **A14. Chat widget voice.** "Talk through the work.", "PORTFOLIO GUIDE", "Grounded in published portfolio details."
  - Fixed: Chat renamed "Ask the site", with plain status and greeting text.
- [x] **A15. The repo grid shows this site's own GitHub description**: "🚀 Welcome to my digital playground! … passion for clean, elegant design ✨". Also "No description has been added yet." filler on half the cards.
  - Fixed: The site repo and profile repo are filtered out; empty or "NA" descriptions show nothing. The GitHub repo description was changed separately.
- [x] **A16. An ↗ on every single link** (about 20 of them) and em-dashes used as the default punctuation.
  - Fixed: No arrows on links, no em-dashes in the copy.

## C. Visual design

- [x] **C1. The default palette.** Off-white background, navy ink, one soft blue accent, navy "dark section" in the middle.
  - Fixed: Drafting paper and ink in light, near-black in dark, safety orange as the only accent.
- [x] **C2. The default type.** Manrope for everything plus DM Mono for tiny all-caps labels. No display face, no scale contrast: the largest and smallest text were too close.
  - Fixed: Big Shoulders Display (variable) for headings, Instrument Sans for text, DM Mono for small labels. Largest text is about 240px, body is 17px.
- [x] **C3. Rounded cards with a hairline border and a soft shadow**, used for everything.
  - Fixed: No rounded corners, no soft shadows. Rules, square frames and one hard offset shadow.
- [x] **C4. "AK" in a rounded square** as the logo and favicon.
  - Fixed: Wordmark is your name with an orange square; new favicon.
- [x] **C5. Portrait in a card with caption bars**, like a stock team-page component.
  - Fixed: Black-and-white portrait captioned "Fig. 1 The engineer"; colour on hover.
- [x] **C6. Nothing on the page is specific to you.** No element a visitor would remember ten minutes later.
  - Fixed: The drawing-sheet idea ties to your mechanical degree. The name changes weight under the cursor, and the hero has a box that asks your own Bedrock assistant a question.
- [x] **C7. Social card and 404** in the same generic style.
  - Fixed: Both redone in the new style.

## Update: visual theme reverted

The owner did not like the drawing-sheet look. The visual theme (palette, Manrope and DM Mono, rounded cards, dark Work band and contact panel) is back to the original. Everything else stays: the copy, the structure, the three diagrams, the hero question box and the parts list. C1 to C5 and C7 therefore describe the original look again and are no longer fixed; C6 now rests on the copy, the diagrams and the question box.

## Rules for the rewrite

1. No fact gets invented. Everything stated comes from the old page or the public repos. Where the old page was vague (dates, client work), the new one says less, not more.
2. First person, plain words, specific nouns.
3. The design is the original theme; the specific parts are the copy, the diagrams and the question box.
