AgentOS

An autonomous research workflow that turns an open-ended question into a structured, cited report using a coordinated LangGraph pipeline.

  • Five specialist stages: planning, search, retrieval, code execution and critique.
  • Shared graph state with a critic-and-revision loop for report quality.
  • FastAPI streaming, Qdrant memory and Redis caching.

LangGraph provides the control flow for a stateful pipeline with a bounded revision path. Retrieval supplies relevant prior context, search gathers evidence, and the critic checks the draft before the final report is returned. The repository documents an SSE API so clients can observe progress instead of waiting for a single final response.

Engineering questions: state ownership, parallel tool execution, quality scoring, safe code execution and memory lifecycle.

02 / RETRIEVAL SYSTEMSRAG

Hybrid RAG Pipeline

A retrieval pipeline that combines dense semantic search and BM25, merges ranked results, reranks candidates and checks answer grounding.

  • Dense + sparse retrieval with Reciprocal Rank Fusion.
  • Cross-encoder reranking and citation verification.
  • RAGAS evaluation, FastAPI services and conversation history.
QdrantBGEBM25RRFRAGAS
Explore the design decisions ＋

Dense retrieval captures semantic similarity while BM25 preserves lexical matching. Reciprocal Rank Fusion combines rankings without requiring score-scale normalization. A cross-encoder then reranks the shortlist, and citation checks plus RAGAS metrics provide quality signals beyond answer fluency.

Engineering questions: chunking, retrieval recall, rank fusion, reranking cost and faithfulness evaluation.

Healthcare Analytics

A healthcare analytics prototype covering medical-image workflows and patient-outcome prediction, with model interpretability as part of the product surface.

  • Documented MRI and chest X-ray classification workflows.
  • Patient risk, length-of-stay and readmission prediction concepts.
  • React, FastAPI, PyTorch, MLflow and DVC in the documented stack.
PyTorchFastAPIMLflowDVC
Explore the design decisions ＋

The repository describes a product surface that connects image-classification workflows with downstream analytics and interpretability views. Healthcare ML requires particular attention to representative data, leakage prevention, calibration, class imbalance and clinical validation. The public README is a project description, not evidence of clinical readiness.

Engineering questions: model evaluation, reproducible experiments, interpretability and responsible communication of results.
