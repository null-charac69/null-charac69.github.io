# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Personal portfolio (Jekyll on GitHub Pages) plus a chat assistant backed by Amazon Bedrock. No JS build step, bundler, or linter; JS is native ES modules served as-is. Owner constraint: keep everything free — GitHub Pages only, plus the Bedrock chat API on Vercel. Don't add paid services or a custom Pages deploy workflow.

## Commands

- Local site: `bundle install && bundle exec jekyll serve` (only core Liquid is used, so plain `jekyll build` works too).
- Chat API tests: `cd bedrock-api && pip install boto3 && python -m unittest tests/test_api.py`.
- Refresh the repo index manually: `python3 .github/scripts/update_repos.py` (public GitHub API, no token needed).

## Architecture

1. **Static frontend** — `index.html` composes `_includes/sections/*.html` (hero, projects, about, open-source, contact) in `_layouts/default.html`. CSS is split into `fonts/tokens/base/layout/components/responsive`; fonts are self-hosted in `assets/fonts` (Manrope and DM Mono). `_config.yml` supplies `portfolio_api_url` (exposed as `window.PORTFOLIO_API_URL`) and `resume_url` (empty ⇒ "Résumé on request"). New non-site top-level files must be added to `exclude:`.
2. **JS** — `assets/js/app.js` is the single entry (cache-busted by build time). It runs theme/navigation plus the Pune clock and copy-email button directly, and dynamically imports `modules/repositories.js` and `modules/chat.js`, so one failure can't break the page. `chat.js` has its own small markdown renderer and also handles the hero question box (`[data-chat-ask]`).
3. **Repo index** — `public-repos.json` is generated by running `.github/scripts/update_repos.py` manually and committing (no Actions workflows: the account's Actions are billing-locked); `repositories.js` reads it same-origin. Written-up projects are the `[data-repo]` articles in `projects.html`, each with a hand-drawn inline SVG diagram; every other repo (minus the site repo and profile repo) appears as a row under "Repos".
4. **Design and copy** — The visual theme is the original one: off-white and navy with a soft blue accent, Manrope, rounded cards, a dark Work band and dark contact panel, light and dark modes. (A drawing-sheet theme was tried and reverted at the owner's request; don't bring it back.) Copy is first person and plain; `REDESIGN_CHECKLIST.md` lists the patterns that were removed for reading as AI-generated (numbered kickers, headline formulas, lists of three, filler labels). Don't reintroduce them, and don't state facts about Anant that aren't already on the page.
5. **Chat API (`bedrock-api/`)** — Vercel Python function (`api/index.py` → `core.py`, `ratelimit.py`). Bedrock Converse, model `global.moonshotai.kimi-k3.1`, `ap-southeast-2`. Facts the model may use live in `PORTFOLIO_CONTEXT` in `core.py` — update it when site content changes. Output tokens are capped low on purpose (cost); the per-IP rate limiter is best-effort per warm instance. Secrets are Vercel env vars (see `DEPLOYMENT.md`).
